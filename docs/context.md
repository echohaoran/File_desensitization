## 2026-08-17：保留格式脱敏下载

- 修复文档类文件下载被错误导出为纯文本、造成段落与表格丢失的问题。

- 使用 ego-browser 尝试查看 Actions 页面时 GitHub 连接被浏览器环境以 `ERR_CONNECTION_CLOSED` 中断，改用只读 GitHub CLI 日志定位失败步骤。
