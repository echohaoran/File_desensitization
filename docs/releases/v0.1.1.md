## 版本更新

- 优化桌面安装包：Electron 安装器启用最高压缩级别，后端移除不参与运行的测试、交互式、可选 Presidio/spaCy 与数据分析模块。
- Windows 与 macOS 安装包统一命名为 `desensitization_0.1.1.格式`。
- 修复 Windows 打包脚本与 MSI 图标链接问题；发布流程可自动附带 DMG、MSI 和 SHA-256 校验和。

## 使用提示

- Windows 请下载 `.msi`，macOS Apple Silicon 请下载 `.dmg`。
- LibreOffice 保持为可选外部组件；仅 DOCX→PDF 转换需要它。
